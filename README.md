# shadcn-light-design

Светлая дизайн-система для проектов на [shadcn/ui](https://ui.shadcn.com) (Tailwind v4, Base UI).
Бумага, чернила и ровные колонки цифр: тёплая нейтральная шкала, шалфейный бренд,
Tektur в заголовках, JetBrains Mono в интерфейсе, Inter — только в связном тексте.

## Что внутри

| Путь | Что |
|---|---|
| `src/index.css` | Вся тема в структуре `shadcn init`: `@theme inline` → роли → палитра (6 шкал) → шкала заголовков `type-*` → `@layer base` |
| `src/components/ui/*` | Все компоненты shadcn — побайтово как в реестре, кроме трёх правок из `UPSTREAM.md` |
| `registry.json` | Реестр для `shadcn add` из GitHub — генерируется `pnpm registry`, руками не правится |
| `scripts/build-registry.mjs` | Генератор `registry.json` из `index.css` |
| `src/showcase/*` | Витрина: страницы «Цвета», «Типографика», «Форма и тени», по странице на компонент; поверхность превью переключается в шапке |

## Установка в свой проект

Проект на shadcn (Tailwind v4, стиль `base-nova`):

```bash
pnpm dlx shadcn@latest add guru31337/shadcn-light-design/light-design
```

Поставит тему (роли, шрифты, радиус, шкалу заголовков) и три изменённых компонента
(`button`, `badge`, `alert`). Остальные компоненты — штатные из shadcn. Отдельно: `…/theme`,
`…/button`, `…/badge`, `…/alert`.

## Команды

```bash
pnpm install
pnpm dev        # витрина
pnpm lint       # ESLint
pnpm build      # проверка типов + сборка
pnpm registry   # пересобрать registry.json после правок темы или компонентов
```

## Правила

Полные правила работы с репозиторием — в [`AGENTS.md`](AGENTS.md), отличия компонентов от оригинала shadcn — в [`UPSTREAM.md`](UPSTREAM.md).

### Кратко

- Дизайн живёт в `src/index.css`; компоненты shadcn побайтово как в реестре, кроме трёх
  правок из `UPSTREAM.md`.
- Компоненты используют только роли (`bg-primary`, `text-muted-foreground`, `border-border` …).
- Радиус один — `--radius` (сейчас 0.25rem), остальные shadcn считает от него.
- У каждого элемента видимая граница на любой поверхности: сплошная заливка или рамка.
- Тени — только у слоёв над страницей.

## Открытые вопросы

1. **Нажатый `Toggle` почти не виден.** shadcn красит его `bg-muted`, а `--muted` почти
   совпадает с `--card` (1.12:1). Варианты: затемнить `--muted` (потемнеют также утопленные
   блоки, подвал карточки, наведение) или оставить как в стандартной теме shadcn.
2. **Недоступное поле заметно серое.** shadcn использует `--input` и как рамку поля, и как фон
   недоступного поля (`bg-input/50`); наш `--input` тёмный ради рамки ≥3:1. Принять или сделать
   рамку полей светлее.
3. **Неактивная вкладка `Tabs`** — текст `text-foreground/60` с прозрачностью; проверить контраст
   на этапе 2.
