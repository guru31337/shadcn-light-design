# shadcn-light-design

Светлая дизайн-система для проектов на [shadcn/ui](https://ui.shadcn.com) (Tailwind v4, Base UI).
Бумага, чернила и ровные колонки цифр: тёплая нейтральная шкала, шалфейный бренд,
Tektur в заголовках, JetBrains Mono в интерфейсе, Inter — только в связном тексте.

## Что внутри

| Путь | Что |
|---|---|
| `src/index.css` | Вся тема в структуре `shadcn init`: `@theme inline` → роли → палитра (6 шкал) → шкала заголовков `type-*` → `@layer base` |
| `src/components/ui/*` | Все компоненты shadcn — побайтово как в реестре, кроме трёх правок из `UPSTREAM.md` |
| `registry.json` | Реестр для `shadcn add` из GitHub — генерируется `pnpm registry`, руками не правится |
| `scripts/theme.ts` | Разбор `index.css`: палитра, роли с подставленными значениями, перевод в sRGB |
| `scripts/build-registry.ts` | Генератор `registry.json` из `index.css` |
| `src/showcase/contrast-rules.ts` | Пары ролей и пороги контраста — общие для теста и витрины |
| `tests/contrast.test.ts` | Тест контраста по `index.css`: каждая пара на трёх поверхностях |
| `src/showcase/*` | Витрина: основа (цвета, типографика, форма) и все компоненты shadcn по группам; поверхность превью переключается в шапке |

## Установка в свой проект

Проект на shadcn (Tailwind v4, стиль `base-nova`):

```bash
pnpm dlx shadcn@latest add guru31337/shadcn-light-design/light-design
```

Поставит тему (роли, шрифты, радиус, шкалу заголовков) и три изменённых компонента
(`button`, `badge`, `alert`). Остальные компоненты — штатные из shadcn. Отдельно: `…/theme`,
`…/button`, `…/badge`, `…/alert`.

## Команды

```bash
pnpm install
pnpm dev        # витрина
pnpm lint       # ESLint
pnpm test       # тест контраста по index.css
pnpm build      # проверка типов + сборка
pnpm registry   # пересобрать registry.json после правок темы или компонентов
```

## Правила

Полные правила работы с репозиторием — в [`AGENTS.md`](AGENTS.md), отличия компонентов от оригинала shadcn — в [`UPSTREAM.md`](UPSTREAM.md).

### Кратко

- Дизайн живёт в `src/index.css`; компоненты shadcn побайтово как в реестре, кроме трёх
  правок из `UPSTREAM.md`.
- Компоненты используют только роли (`bg-primary`, `text-muted-foreground`, `border-border` …).
- Радиус один — `--radius` (сейчас 0.25rem), остальные shadcn считает от него.
- У каждого элемента видимая граница на любой поверхности: сплошная заливка или рамка.
- Тени — только у слоёв над страницей.

## Состояние

Сделано:
- Тема: палитра из пигментов исходного проекта, роли shadcn + `success`/`warning`/`info`,
  шрифты (Tektur / JetBrains Mono / Inter), один `--radius`.
- Компоненты shadcn как в реестре; правки только в `button`, `badge`, `alert`.
- Реестр: установка одной командой проверена на чистом shadcn-проекте.
- Тест контраста (`pnpm test`): 43 пары ролей и пары из классов компонентов на трёх
  поверхностях плюс охват sRGB у палитры. Те же пары — таблицей на странице «Цвета».
- Витрина: все компоненты shadcn на страницах по группам — действия, формы, оверлеи,
  навигация, данные, обратная связь, раскладка, чат (кроме `DirectionProvider` — у него нет
  вида). Поверхность превью переключается в шапке, всплывающие слои проверены открытыми.

Решено на этапе 2:
- **Выбранное — `accent`**: нажатый `Toggle`, выбранный пункт `Command` — как подсвеченный
  пункт меню и активный пункт `Sidebar` (правило по `data-slot`). `brand-200` на тон темнее,
  чтобы `accent` держал 1.3:1 и на утопленной поверхности. «Включено» у `Checkbox`, `Radio`,
  `Switch` — `primary`.
- **Дорожки `Slider`/`Progress`, `Skeleton`** — нейтральная заливка `secondary` вместо `muted`,
  который пропадал на утопленной поверхности.
- **Недоступное поле** остаётся серым (`bg-input/50` из shadcn): так оно отличается от пустого.
- **Неактивная вкладка `Tabs`** не держала 4.5:1 (4.21) — текст (`--foreground` и остальные
  `-foreground` того же цвета) перенесён на `neutral-950`: теперь 4.80.
- **Наведение на `Button` default** (`bg-primary/80`, 4.17) и **ошибка во вложении**
  (`text-destructive/80`, 4.04) — ступени `brand-700` и `red-700` на тон темнее: 4.58 и 4.56.
- **Поиск в `Command`/`Combobox`** выглядел недоступным полем — правило по `data-slot`.
- **Заголовки `h1–h4` больше не стилизуются глобально**: правило делало `PopoverTitle` 24px и
  переводило шапку `Accordion` на Tektur. Шкала `type-*` ставится классом.
- **Палитра графиков остаётся**: ориентир — обычное зрение, по нему палитра проходит проверку
  различимости. У двух и более серий всегда легенда. Зелёный и красный (`chart-3`, `chart-4`)
  рядом с P&L читаются как рост и падение — правило для `DESIGN.md`.
- **Варианты без рамки** (`Item muted`, `Bubble muted/tinted/destructive`) на утопленной
  поверхности не используются: там — `outline` или `secondary`, компоненты не меняются.
- **Край `Card`, `Popover`, `Dialog`, меню** — `ring-1 ring-foreground/10` из shadcn, 1.23:1
  против 1.3 у роли `border`. 10% даже от чёрного дают не больше 1.25 — значением не решается;
  принято как известное исключение (в тесте — TODO).

## Открытые вопросы

1. **Отступы `Popover` и `HoverCard` — 10px** (`p-2.5`, плотность стиля nova; у `Dialog` и `Card`
   16px). С формой внутри тесно. В `index.css` чисто не решается: отступ зашит в класс. Варианты:
   передавать `className="gap-3 p-4"` там, где внутри форма (штатный способ shadcn для раскладки),
   или разрешить правку `popover.tsx` и `hover-card.tsx` третьим случаем правила №1 — тогда они
   уходят в реестр.
